# 对话优先改造实施记录

依据：[CR-003](../implementation/CR003_CONVERSATION_FIRST_HARNESS.md)。授权：用户要求将必填表单式交互改为 Agent 主导的自然对话，以工程 Harness 约束不稳定执行。

1. 修订验收：新项目可以一句话开始、未知信息保持未知、摘要及确认可追溯、从主对话修改方向。
2. Application：有界 intake 运行与持久草案/来源，提出和确认分离，复用现有 runtime、权限和取消；定向负向测试先红后绿。
3. Bridge/UI：首页/新项目默认直接对话；已有未确认项目继续对话；方案确认与后续写作保持同会话；RPC 协议同步。高级字段入口仅可选。
4. 验证及交付：Runtime/Bridge/UI/Desktop 对应检查、结构与边界审查、构建新候选。安装包统一 `output/desktop`；不覆盖运行中的用户程序或原项目。

主 Agent 负责文档、Bridge、UI 和交付；后端澄清模块委派 `gpt-5.6-sol / high`，因模块范围明确但涉及持久化/权限/运行时集成。最多两个独立子任务，不重复调查，不估算 token 或费用。所有既有未跟踪实现保留在当前工作区，不从 HEAD 新建缺少它们的 worktree，不整体暂存/提交。

状态：本轮入口、Application、Bridge 与 UI 改造已实现，定向与既有测试及合成模型浏览器主旅程通过，rc.8 已生成并通过协议 v19 打包冒烟。具体证据和用户复测步骤见 `docs/testing/CR003_CONVERSATION_RESULTS.md`。此前 CR-002 完整真实写作未通过的记录保留；本次不能以新增澄清能力替代完整写作验收，真实模型自然对话及客户端人工体验仍待测试。
