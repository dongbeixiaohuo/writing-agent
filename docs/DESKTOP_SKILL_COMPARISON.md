# 桌面与 Claude Code Skill：能力和边界

更新：2026-10-23。这是实现边界说明，不是“完全迁移已验收”的声明。当前公开候选为 [RC88](launch/RC88_RELEASE_EXECUTION.md)；[RC87 发布记录](launch/RC87_RELEASE_EXECUTION.md)与[RC80 审计后调整](implementation/RC80_AUDIT_FOLLOWUP.md)保留历史验证范围，不代表旧安装包具有后续新增行为。仍受[发布门禁](testing/RELEASE_GATE.md)约束，自动回归不等于所有迁移场景完成真实模型与人工验收。

RC88 新增默认关闭的 DeepSeek 搜索，使用独立 Key，显式启用后优先请求并按成功搜索请求计费；仅取摘要，不额外调用付费 Fetch。重复读取无进展时暂停、过长限流等待可恢复，同轮已授权来源快照可复用。作者确认、标题选择与事实门禁仍保留。合成接口及流程回归不等于 DeepSeek 真实付费实测或真实模型完整写作；安装、升级与 GPU 边界以 RC88 发布记录为准，正常 GPU 不能由禁用硬件加速的 smoke 结果证明。

| 方面 | 独立桌面版 | Claude Code Skill / 插件 |
|---|---|---|
| 启动环境 | Electron 安装包、自有运行时 | Claude Code 加载 Skill/agent |
| 模型配置 | 图形化供应商、协议、Key 与模型切换；当前源码的可用标记只绑定实际测试的配置，换模型需重测 | Claude Code 自身的模型配置 |
| 核心协作 | 导演调度、隔离专家调用、持久阶段与确认点；自然语言确认已有专项测试，完整用户旅程仍需验收 | Skill 总控、subagent 与工作流文件约束 |
| 专家方法 | 已迁移的写作专家指令与程序化保存/版本约束；不等于逐字或行为完全相同 | `claude-runtime/agents/` 定义方法与输入输出 |
| 数据与恢复 | SQLite、事件、版本、停止/续接 | 文章文件、manifest 和 Claude Code 会话 |
| 资料输入 | 显式 HTTP(S) 链接安全读取；当前源码先尝试读取再提案，每轮最多三个，多余或失败项明确披露，不冒称已读；不支持绕过登录/验证 | 依赖 Claude Code 实际可用且获授权的读取工具 |
| 风格与审校 | 风格参考、编辑/发布审校、三个隔离的普通模拟读者、集中修订、去 AI 味；当前源码支持按需重测当前成稿与已选标题，不自动重跑全文流程 | 完整 Skill 流程；样本和风格状态按其契约 |
| 研究补查 | 当前源码可用已启用的 DeepSeek/Parallel/Tavily 对提纲前关键缺口最多补查两次；可不搜索，失败不挂起，不等同开放式深度研究 | 依赖 Claude Code 实际工具与研究工作流 |
| 最终事实核查 | 重点核对易错的重要时间、人物、事件、数字和引语，不逐句找论文出处；中低风险提示不阻断；关闭搜索时如实说明未联网验证 | 原 Skill 的独立核查流程；桌面后续轻量规则不反向更改原版 |
| 配图 | 已有配图策划与确认；本次未接入新增付费自动出图服务 | 原 Skill 包含图片生成流程，另需对应服务配置 |
| 导出 | 当前版本核查约束下的 TXT/HTML，与工作备份区分 | 工作流核查后清稿与可选 HTML |
| 发布后表现与学习 | 不宣称与原 Stage 14 指标/复盘流程完全等价；需单独对照验收 | 原流程包含可选发布指标和复盘文件 |
| 旧项目迁移 | 提供扫描/预览/导入路径；不是自动识别任意旧目录即无损升级 | 保留原文件工作区 |

共用的是写作理念、方法与部分领域约束，不是同一个执行宿主。桌面版不需要 Claude Code，也不会因配置了桌面模型而替 Claude Code 配置模型。

事实核查的当前桌面维护源是[轻量事实核查合同](architecture/FACT_CHECK_CONTRACT.md)。没有每点引用本身不算事实错误；真实高风险错误或未决项仍需说明并处理。模拟读者不充当事实核查员，也不冒充真实用户调研。

Local Web 开发入口与 Electron 安装包不是同一传输层：当前源码为前者增加滑动会话有效期和过期重连，保留同工作区及可恢复的项目/会话选择；Electron IPC 不使用这套令牌。未知结果的写操作不会因为断线自动重复执行。

历史 Tauri `app-preview-0.1.0` 是第三种旧交付物，不属于上述新桌面实现，不应再引导新用户下载。历史源码从对应 Tag 获取；当前仓库不再跟踪本地 `writing-agent-app/`。
