# Writing Agent 桌面版快速开始

更新：2026-09-30。当前候选为 **1.0.0-rc.58**，正在完成公开 RC 发布检查。以下是当前实现的操作说明，不代表稳定版承诺。[已知限制与发布门禁](testing/RELEASE_GATE.md)

## 1. 下载、安装与升级

公开批准后，安装包会放在[本仓库 Releases](https://github.com/dongbeixiaohuo/writing-agent/releases)中，标题明确标注“桌面版”和支持平台。下载 Windows x64 的 `Writing-Agent-Setup-版本号-x64.exe`，不要下载 `Source code.zip` 当作软件，也不要误装旧 `app-preview-0.1.0`。

维护者本地安装包统一放 `output/desktop`；这不是互联网下载地址。本次 RC 未签名，Windows 可能显示未知发布者提示。核对仓库来源与 SHA-256，不要关闭安全软件来强行安装。建议使用默认本地安装目录，不安装到 OneDrive 等云同步目录。

升级前：

1. 在“设置 → 数据与诊断”备份工作区，保留在安装目录外。
2. 保存工作并退出旧程序；关闭窗口时选择“退出程序”，不要仅最小化。
3. 运行新版安装包，检查版本与安装位置。安装器设计为先移除旧程序，再安装新版本，保留项目和设置。
4. 升级后在关于页核对版本，打开旧项目，确认稿件和模型配置仍在。

候选的安装与升级实测范围以 Release 附件及发布门禁记录为准，不代表所有 Windows 环境和历史版本组合均已验证。当前没有自动更新；需要手动获取新包。不要直接降级打开新版数据库，回退先恢复与旧版本兼容的备份。

## 2. 配置模型

进入“设置 → 模型”：

- 新手选择预置供应商，核对国内/国际、通用 API/套餐接口，再填 API Key 和模型 ID。
- 自定义接口需填协议和地址：OpenAI Chat Completions、OpenAI Responses 或 Anthropic-compatible。以实际服务商支持为准，不能仅因“兼容 OpenAI”就改成 Responses。
- 点击保存并验证连接。测试会发出真实请求，可能产生用量；失败时看具体错误，不必重复建立项目。
- 已保存模型可在主对话输入框附近切换；本轮运行中不要假设切换会改变已经发出的请求。

Key 优先放在系统凭据存储，不会明文写入模型配置。系统保存不可用时，界面会提示仅当前会话有效，重启后需重填。连接测试通过只是代表性能力检查，不保证整篇长任务在该服务上永不超时或报错。

## 3. 选择是否联网核查

进入“设置 → 搜索”：

| 选择 | 行为 |
|---|---|
| 开启 Parallel | 使用无需 Key 的免费搜索服务；可能受服务可用性或限额影响 |
| 开启 Tavily | 填入 Tavily API Key，用量按该账户规则 |
| 两者均开启 | Parallel 优先，仅请求失败时使用 Tavily |
| 两者均关闭（默认） | 模型结合已有材料与自身知识复核，未联网验证 |

修改后点保存。编辑 Tavily 时 Key 留空表示保留原 Key，不代表删除。

**不选择外部搜索，文章仍可能有事实错误；选择搜索也不等于已证实正确。** 搜索结果只是证据候选，核查专家仍需判断来源、时效和相关性。重要数字、引用、政策等应人工复核。桌面发送前会展示确切检索词与搜索服务，经你确认才发送；不要同意外发私人或客户机密。拒绝后本轮使用已有材料与模型复核，并说明未联网验证的限制。

## 4. 写第一篇文章

1. 点击“新建项目”，直接在主对话描述想法。也可以说“我还没想好写什么”。
2. 与助手讨论读者、篇幅、发布场景和材料。需要亲历时提供真实经历，不必一次填完表单。
3. 确认写作方向；共创模式按阶段查看、讨论并确认。认可、修改和提问都从主对话输入。
4. 看专家名称和阶段结果。读者审校模拟目标平台的阅读感受，并非真实读者调查；去 AI 味不应编造亲历。
5. 确定标题、审阅当前稿件，继续事实核查。
6. 主对话的“查看当前稿件”打开稿件；“稿件与版本”用于阅读、版本对比、材料过程及导出。

左侧项目名选择已有项目，右侧加号在该项目中新建对话。主对话用于普通交流，运行记录用于查看模型请求、工具和专家执行情况；模型请求次数不等于写作阶段数。

## 5. 核查状态和导出

- **尚未核查**：稿件可以保存、继续讨论，但不能当作已核查终稿。
- **有事实问题待处理**：继续对话，说明如何补充或修改；不要为了导出而把不确定事实标成通过。
- **旧报告失效**：正文、标题或证据发生变化，旧报告仍可查看，但当前版本需要重新核查。这不是稿件丢失。
- **通过**：可从稿件工作台导出正式 TXT/HTML；导出不会自动发布到公众号或其他平台。
- **工作备份**：用于保留未完成内容，不等于正式交付。

已知体验问题：等待阶段确认时，旧报告失效提醒仍可能与确认提示同时出现。当前应先按主对话确认或提出修改，不必重新建项目；此提示层次仍待优化。

## 6. 数据和隐私

- 项目数据：Windows“文档”文件夹下的 `Writing Agent\Workspace`。默认常见位置为 `%USERPROFILE%\Documents\Writing Agent\Workspace`；若文档目录已重定向，则跟随系统实际位置，不要按示例手工移动数据库。
- 应用设置：`%APPDATA%\Writing Agent`。
- 凭据：系统凭据存储；受限环境可能仅在当前会话保存。
- 模型配置和系统凭据不应假设包含在工作区数据库备份里，换电脑可能需重新配置。

卸载默认保留项目数据。项目删除是另一项永久操作，删除前先备份。工作区恢复会替换当前库，不是合并两个库；按界面提示核对备份并保留恢复前副本。

本地保存仍会在写作时把相关内容发送到你配置的模型服务。模型、外部搜索及读取来源的网络访问，应与实际材料授权范围一致。

## 7. 遇到问题

| 现象 | 先做什么 |
|---|---|
| 连接验证失败 | 核对地区/套餐、协议、地址、模型 ID，再看错误详情；不在 Issue 粘贴 Key |
| 等待很久 | 看当前阶段、运行记录和首个内容时间；可停止，已保存内容保留；重试可能产生额外用量 |
| 旧核查失效 | 当前稿件变化后的正常状态，完成必要确认并重新核查 |
| 软件启动崩溃 | 记录版本、Windows 版本、是否升级安装和错误截图；不要先删项目或覆盖数据库 |
| 确认后不继续 | 保留会话和脱敏运行记录，记录原话与当前阶段，不靠重复输入口令规避问题 |

反馈入口：[GitHub Issues](https://github.com/dongbeixiaohuo/writing-agent/issues)。请不要上传完整私人数据库或未脱敏诊断。
