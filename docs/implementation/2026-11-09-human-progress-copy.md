# RC97：面向作者的过程说明

主对话现在说明哪位 Agent 正在做什么：写作助手梳理想法、资料研究查找资料、主笔写稿、审校审读、读者反馈、语言润色、标题策划和事实核查。风格库也分别说明风格分析与试写任务。

不再把连接状态、数据事件次数、工具参数准备过程、私有推理声明和请求计数作为主界面进度。描述绑定实际分配的角色与实际搜索操作，不根据模型传输事件猜测思考过程，不模拟百分比。较长等待仍提示可以等待或停止。

计时保留原来的累计计算，标签简化为“本轮已用时”；已完成成果显示“处理用时”。参考材料仍可手动展开。公开的正文和审校回复继续逐步显示，内部操作预览不再混入主对话。

暂停、保存失败、搜索恢复和重试说明保留三件事：是否完成、哪些内容仍在、接下来可以怎样操作。未知外部操作仍明确提示重复执行风险，并要求明确重试决定。服务建议的重试时间保持原校验与限制。模型配置和账户额度错误保留可操作的设置提示。运行记录仍保留错误代码、请求详情与服务返回信息。

这次不修改工作流、数据库或用户稿件。RC97 同时包含前一提交的风格指南 v3；旧风格继续可用，新提取保留具体写法、连贯原文和迁移示例。安装包保持原 appId、NSIS GUID 和保留用户数据的升级配置，不自动安装到用户当前目录。
