# 风格选择与风格包实施计划

> 后续发布更新（2026-11-01）：上述功能已纳入 RC93 公开候选，安装、升级和下载校验见 [RC93 发布记录](../launch/RC93_RELEASE_EXECUTION.md)。文中的“未打包/未发布”等描述仅指原实施阶段；真实模型风格效果尚未在本次发布重新验收。

**Goal:** 选风格只选名字，不污染输入框；以有界风格包改善结构、节奏和表达的迁移。

**Architecture:** 使用独立、用户授权的项目风格快照，后台按 ID 和版本解析；风格包由本地统计、一次模型归纳和原文段落片段组成。按写作阶段投影，事实核查不接收样文片段。兼容 RC92 的描述型卡与可选证据，不引入新的完成门禁。

**Tech Stack:** TypeScript、Zod、React、现有 SQLite artifact 存储与桌面桥接。

用户已确认设计；当前分支保留既有 RC92 修改，不切换工作区、不提交、不发布。按 Code / writing-plans 的可验证步骤在本会话实施，不另建重复实现。
