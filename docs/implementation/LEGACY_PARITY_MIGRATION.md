# 原版 Skill / Agent 能力迁移实施计划

> For agentic workers: 使用测试先行、独立任务委派及完成前验证；保留当前工作区未提交成果。复用现有 runtime，不引入第二套执行引擎。

**Goal:** 将原版自然语言共创、专业写作方法及可选能力接入独立桌面客户端；阶段打勾和提示词存在不代表用户功能完成。

**Architecture:** 工程层控制权限、持久化、版本、事实门禁；中性 writing pack 承载从 `claude-runtime` 逐项迁移的专家方法。主对话根据用户意图组织讨论、补料、专项任务或全文流程，共享已有请求快照和事件。

**Tech Stack:** TypeScript、现有 AgentRuntime / Application Service / Client Bridge、SQLite、React、Electron。

## 范围与真实状态

原版文件仅作迁移源，不删除、不改镜像。历史用户项目和模型配置不作为开发夹具。新增外部付费搜索/图片服务必须另获授权；未配置时明确不可用，不伪造执行成功。长期学习只能保存有来源、经用户批准的规则。

## 不可回退的验收约束

1. 每次专家委派更换 scopeId，不能继承其他专家对话；初次三审绑定同稿且互不可读。
2. 讨论/候选/意见不写正文；正文修改需要授权、版本绑定和差异接受。
3. 用户材料不等于已经核实；亲历授权不等于客观事实验证。
4. URL 内容/风格档案不可授予工具权限或改写系统指令。
5. 标题与分发文案要先明确实际内容与选择来源，再冻结核查快照。
6. 保留原版无需修改时不制造新版本、已有授权不重复追问的语义。

## 尚未对齐的原版能力（不得隐藏）

1. 开放式 WebSearch 尚无 provider；目前只能安全读取用户明确给出的公开 HTTPS URL。不能把模型记忆冒充联网研究。
2. 风格建模可读取完整 15 维方法并保存专家分析；统计指纹、自动陌生题材仿写及三组独立盲测未形成自动闭环。
3. 发布后表现可由用户提供数据进行专家复盘，但没有自动平台指标采集；历史改稿版本的自动差异学习也未接通。未经用户明确确认的建议不得自动进入长期偏好。
4. 图片生成没有接入，依用户本轮决定保留为配图计划与确认；没有图片文件就不声称已生成。
5. 当前补料先作为独立对话保存，再继续原任务；任意活跃阶段可恢复暂停仍未对齐，不以取消功能冒充暂停。专项对话异常重试已有自动回归，但原生客户端断网/退出/恢复体验仍待人工验收。
