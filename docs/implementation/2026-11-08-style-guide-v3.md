# 风格提取与写作应用：完整指南及连贯示例

本次解决的是风格经过提取、保存和写作传递后，只剩通用形容词和短句片段的问题。新提取结果使用风格包 v3；旧版个人风格、项目快照及两个内置候选继续可用，不自动改写或升级用户数据。

## 提取与展示

- 一次模型调用提取有辨识度的选择：切口、选材、推理或叙述、读者关系、语言。每条包含具体动作、适用情形、容易学歪的方式，不强制每个维度都有内容。
- 写作指南保留完整规则及条件，取消原有逐条 140 字符和整卡 1,800 字符压缩；保存上限为 16,000 字符，超过上限明确报错，不静默裁剪。
- 模型选择编号，程序从源文取回连续完整段落，最多 8 段、4,000 字符，并保留逐例分析与换题迁移说明。不跨节选缺口拼接，不把未发送的段落当作模型已读。
- 可选改写对照由模型另拟假设情境，两版保持相同信息和立场，明确标为模型创作。直接复用原文段落的对照被舍弃并提示；这只是直接复用检查，不声称语义查重。
- 仅返回概述、缺少具体条件、没有有效原文示范时，本次提取失败，原保存版本保持不变。用户仍可以手动维护旧风格。
- 界面展示可编辑指南、原文示范、分析和迁移方法；分析记录与可编辑指南分开，手工修改指南优先。

## 写作时如何应用

- 项目选中的风格由后台解析成固定版本快照，不作为用户对话文本拼接。
- 导演读取完整指南，避免调度时重新指定冲突的统一结构；提纲、主笔、专业审校、修订、语言终审、标题读取完整指南，并按角色选取最多 3 个完整原文示例及 1 个相关对照。优先不同写法及相关类别，不再取每个示例的前 250 字符。
- 应用层系统提示明确要求落实本题适用的写法，尊重用户本轮要求及手动指南；不强制套用全部动作，不输出执行清单。统计指标作为观察辅助，不再作为写作配额注入。
- 原文与对照保持参考数据身份，不执行其中的命令，不继承人物、事实、立场或亲历；研究、事实核查、模拟读者不接收该风格包。
- 试写走同一指南和完整示例组装逻辑；选中风格本身不修改已完成正文、标题或事实核查状态。

## 兼容与资源边界

风格包 JSON 增量兼容，不需要数据库迁移。原样文仍最多 10 份；分析仍使用最多 24,000 字符的代表性输入及最多 480 个段落记录，界面披露实际分析量。取消的是输出指南和示例的中途截断，并非向模型无限发送全文。

单次提取输出预算从 4,096 调为 8,192 tokens，整体超时仍为 120 秒，不自动循环重试。完整指南和示例会增加写作输入量。保存的包最多 6 条新提取规则、6 个新提取示例、3 个对照；旧版兼容 schema 的容量更宽。新提取结果的质量仍需真实题材试写判断，字段齐全不等于作者风格复刻成功。

## 使用与验收

1. 原 App → 风格库 → 打开原风格 → 使用已有样文“提取风格”。
2. 阅读指南、连贯原文及迁移说明，必要时编辑，点击“保存到风格库”。
3. 在测试项目里重新选择保存后的风格版本；旧项目不会自动改用新版快照。
4. 用相同选题与素材测试，比较切口、推进、读者关系和句段表达。保留原稿用于对照。
