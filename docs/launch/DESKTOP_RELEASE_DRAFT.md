# Writing Agent 桌面版：Release 文案草稿

**仅本地草稿，不用于直接公开。当前候选 rc.57，尚无最终发布 commit/Tag。** 发布前由维护者填入最终版本、源码 SHA、安装包哈希和验证结果，再按 [Release Gate](../testing/RELEASE_GATE.md)签收。不得把本页标题当作已发布版本。

## 这是什么

Writing Agent 是通过对话逐步完成文章的写作助手。无需安装 Claude Code；配置模型 API 后，与导演、主笔、审校、读者模拟、去 AI 味与事实核查专家协作。

原 Claude Code Skill 继续保留在同一仓库。本次是独立桌面入口，不是要求 Skill 用户强制迁移，也不宣称两者所有能力完全相同。

## 这次带来什么

- 图形化模型供应商预置、自定义协议与对话内模型切换。
- 主对话中的阶段结果、自然语言讨论与确认；保存稿件及历史版本。
- 编辑/发布/平台读者审校、集中修订、去 AI 味与核查。
- 搜索设置：Parallel 免费搜索、Tavily Key、关闭外部搜索时的风险提示。
- 当前稿件阅读、工作备份和核查约束下的正式导出。

## 下载和使用

发布批准后，本页 Assets 中的 `Writing-Agent-Setup-版本号-x64.exe` 才是 Windows 安装包，`Source code.zip` 是源码。Windows x64 以本次实测系统矩阵为准；不宣称支持尚未提供产物的平台。

安装 → 设置模型并验证 → 新建项目并对话 → 确认阶段结果 → 阅读、核查、导出。详细说明：[桌面快速开始](../QUICKSTART_1_0.md)。

## 升级与费用

先备份工作区并退出旧程序，再安装新包。安装器设计为保留项目与设置；这里必须补充**该发布候选**的真实升级结果，不引用旧 RC 代替。当前没有自动更新。

模型及 Tavily 用量由自己的服务商账户计费。项目保存在本机，但模型/外部搜索会接收必要请求内容。不开外部搜索时是未联网的模型复核，仍可能有事实错误；开启搜索也不保证绝对正确。
