# Writing Agent 桌面版：Release 文案草稿

**1.0.0-rc.58 / Windows x64 已公开发布为 Pre-release。** 本文件保留发布文案来源，实际下载与资产说明以 [GitHub Release](https://github.com/dongbeixiaohuo/writing-agent/releases/tag/desktop-v1.0.0-rc.58) 为准；维护者已接受未签名风险。最终源码为 `cdfe876df1d275b617189d1408217227877d6699`，验证详情见 [执行记录](RC58_RELEASE_EXECUTION.md)。

## 这是什么

Writing Agent 是通过对话逐步完成文章的写作助手。无需安装 Claude Code；配置模型 API 后，与导演、主笔、审校、读者模拟、去 AI 味与事实核查专家协作。

原 Claude Code Skill 继续保留在同一仓库。本次是独立桌面入口，不是要求 Skill 用户强制迁移，也不宣称两者所有能力完全相同。

## 这次带来什么

- 图形化模型供应商预置、自定义协议与对话内模型切换。
- 主对话中的阶段结果、自然语言讨论与确认；保存稿件及历史版本。
- 编辑/发布/平台读者审校、集中修订、去 AI 味与核查。
- 搜索设置：Parallel 免费搜索、Tavily Key、关闭外部搜索时的风险提示。
- 当前稿件阅读、工作备份和核查约束下的正式导出。

## 下载和使用

Release 页 Assets 中的 `Writing-Agent-Setup-1.0.0-rc.58-x64.exe` 是 Windows 安装包，`SHA256SUMS.txt` 用于校验，`Source code.zip` 是源码。普通用户无需安装 Node.js、Python 或 Claude Code。本次只分发 Windows x64，不宣称支持尚未提供产物的平台。

**本次 RC 未签名**，Windows 可能显示“未知发布者”或 SmartScreen 提醒。请核对本仓库来源与 SHA-256；不要求关闭杀毒软件或系统安全防护。建议使用默认本地安装目录，不安装到 OneDrive 等云同步目录。

安装 → 设置模型并验证 → 新建项目并对话 → 确认阶段结果 → 阅读、核查、导出。详细说明：[桌面快速开始](../QUICKSTART_1_0.md)。

## 升级与费用

先备份工作区并退出旧程序，再安装新包。最终候选在 Windows Runner 完成安装、启动、卸载与 rc.57→rc.58 升级验证，检查旧程序移除、单一安装项、快捷方式和数据目录哨兵文件保留；不代表所有历史数据库迁移都已经验收。当前没有自动更新。

模型及 Tavily 用量由自己的服务商账户计费。项目保存在本机，但模型/外部搜索会接收必要请求内容。不开外部搜索时是未联网的模型复核，仍可能有事实错误；开启搜索也不保证绝对正确。

发送外部检索词前会展示具体文字和搜索服务，由你确认；拒绝后本轮使用已有材料与模型复核。不要同意发送私人信息或客户机密。Parallel / Tavily 均已完成真实搜索和模型核查保存的专项验证，来源网页原文有时仍不可读取，报告会说明使用摘录的限制。

## RC 已知限制

- 不是稳定版，建议从独立测试项目开始，重要稿件另做备份。
- 99 个接入预设不是 99 家厂商实测承诺；账户地区、套餐与支持协议仍需核对。服务商可能出现较长首字等待、限流或中断。
- 原 Skill 能力尚未完全迁移：自动配图、完整量化风格与盲测、发布后指标自动采集等未接入。旧 Skill 仍可继续使用。
- 旧版在 OneDrive 程序目录出现过 GPU 启动异常，具体环境原因未确定；本次不承诺云同步安装目录兼容，不通过关闭安全机制绕过。
- 完整人工桌面旅程、所有历史项目/系统组合及旧 Tauri 数据迁移仍需更多用户反馈。自动安装/模型脚本不等于全部人工体验验收。
- 事实复核不是专业查证保证；无外部搜索时尤其需要人工确认重要数字、引语和时效信息。

本次修复了共创确认叠加旧核查警告、模型端点跨域重定向、Tavily 配置保存失败一致性和插件独立安装依赖范围问题；测试详情见发布门禁与 rc.58 执行记录。

已知问题不能通过去掉 RC 后缀或删除本节变成“已解决”。反馈附版本和脱敏复现记录，不上传 Key、私有数据库或客户材料。
