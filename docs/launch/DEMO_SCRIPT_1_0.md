# Writing Agent 桌面演示与验收脚本

更新：2026-09-30。用于最终候选的真实用户旅程，不预先承诺耗时，不把演示剪辑视为验收证据。当前发布门禁仍 CLOSED。

## 准备

- 独立 Windows x64 测试环境、同一候选安装包及对应 SHA-256；测试升级时保留上一版合成项目和可恢复备份。
- 使用公开或合成材料，录屏不出现 API Key、私人正文、客户信息或私人路径。
- 已配置且获授权使用的模型；展示时写清模型/协议与候选版本，不外推整个供应商目录。
- 核查选择按真实设置记录；如无 Tavily 账户，不伪造其成功画面。

## 一篇文章的完整路径

1. **安装与配置**：核验文件、签名状态，安装后从开始菜单启动；展示模型配置和连接结果。普通用户不需要安装开发环境。
2. **通过对话建稿**：新建项目，输入“想写一篇关于通勤时观察到的小变化的随笔”；让助手自然追问，再补充读者、篇幅及合成场景，不展示过时的必填字段向导。
3. **逐阶段共创**：确认方向后展示当前专家身份和流式成果。提纲出现后先提一次修改意见，再自然表达认可；核对只进入允许的下一阶段。每位需要确认的专家处理完后分别确认，不能一口气跨过用户决策。
4. **保留作者选择**：选定标题后继续核查，确认不会无理由重新选题；局部改稿先看修改范围，再接受并检查新版本与历史差异。
5. **事实复核**：展示素材充分时继续、真实事实疑点时解释并处理；关闭外部搜索时明确未联网。需要联网的样例实际查看来源，不将“搜索成功”剪成“事实通过”。
6. **查看与导出**：主对话打开当前稿件，稿件面板查看版本与导出；只有当前版本确实满足交付条件才展示正式导出，不能换成已通过的 fixture 冒充本篇完成。
7. **退出与恢复**：重开同项目，确认正文、标题、历史和设置保留。模拟停止/重试另作专项，检查不重复覆盖已保存内容。
8. **升级专项**：在隔离环境从上一版升级，检查关闭运行程序提示、卸载/安装进度、单一卸载项及项目/设置保留。不对用户日常实例执行破坏性测试。

## 结果怎么记录

- 保留候选版本、模型、搜索设置、关键步骤结果、真实等待和失败；演示可剪辑，但验收记录保留完整事实。
- 干净机、旧项目升级和真实模型是不同证据，不互相替代。
- 未签名风险、费用、模型发送材料与搜索发送查询的隐私边界应明确告知；不指导关闭系统安全防护。
- 功能尚未验证就注明，不使用 Mock、旧版画面、人工修改核查状态或其他文章的通过结果填补。
- 所有结论回填[发布门禁](../testing/RELEASE_GATE.md)，最终由维护者签收。
