# Writing Agent 1.0 演示脚本

用途：维护者在 RC 验收或发布视频中复现核心用户旅程。总时长约 8 分钟，使用公开/合成材料，不展示 API Key、私人正文、绝对路径或真实客户数据。

## 演示前准备

- 独立 Windows x64 测试机，未安装 DSH、Claude Code、Python 或旧桌面应用。
- 最终候选安装包及同批次 `SHA256SUMS.txt`。
- 经明确费用授权的测试 provider 和限额；录屏前遮蔽 Key。
- `evaluations/cases/writing_quality_cases.json` 中一例合成材料。
- 一份旧版合法合成迁移夹具，不使用真实用户库。

## 镜头顺序

1. **校验与安装（45 秒）**：展示文件名、SHA-256、签名状态和 Windows 版本；安装后从开始菜单启动。
2. **首次配置（60 秒）**：选择协议、填写 HTTPS Base URL/模型；Key 输入后不再回显。说明请求只发给用户配置的服务。
3. **创建项目（60 秒）**：填写主题/读者/篇幅，粘贴合成材料并确认来源角色。
4. **真实写作闭环（120 秒）**：模型调用材料工具，收到结果后保存正文；展示 run 状态、usage/预算和停止能力。
5. **可控修改（90 秒）**：锁定一段，演示冲突拒绝；对另一段生成提案、查看差异并接受，形成新版本。
6. **事实与交付（60 秒）**：正文变化令旧核查 stale；工作备份仍可取回，正式 TXT/HTML 被门禁阻断。使用已核查夹具展示允许出口。
7. **恢复与迁移（60 秒）**：退出重开后状态恢复；扫描旧夹具、预览、导入，在新 UI 打开并说明旧 passed 不继承。
8. **边界与回退（45 秒）**：展示数据目录、诊断预览、第三方声明、unsigned/已知限制和卸载不删用户数据。

## 必须口播的限制

- UI 复用了固定 commit 的 DeepSeek Harness 前端源码切片；Writing Agent 并非 DeepSeek 官方产品。
- 质量结果只能引用已完成的三组盲评；没有结果时直接说“尚未完成”。
- 真实模型兼容性只列已实际执行的模型/端点，不以 fixture 外推所有供应商。
- RC 是预发布版；签名、SmartScreen、支持系统和迁移范围按 Release 原文说明。

## 演示验收

录屏后由另一人核对：无 Key/私人路径、下载资产真实存在、hash 一致、所有功能均来自同一候选、没有把 Mock 或旧 0.1.0 画面剪成 1.0 结果。
