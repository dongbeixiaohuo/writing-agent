## 9/30 追加：PR #15 跨平台 CI 修复

首轮同一提交的 push / pull_request 各运行一次，两轮各失败三项，合计六项失败；根因有三类，不是六个独立产品缺陷：Windows 检出 CRLF 导致来源原始字节哈希不符；风格快照嵌入 CRLF 与 Linux LF 源文件不一致；Windows TEMP 的 8.3 别名与规范路径比较不当。

- `.gitattributes` 为按字节校验的上游文件、风格源文件及镜像固定 LF；新增测试防止遗漏。仍保留原始字节和 SHA-256 校验。
- 新增 `node packages/writing-pack/scripts/sync-legacy-style-data.mjs` 生成命令，只刷新源文本换行和哈希，不改变风格内容、别名、元数据或验证状态。
- 路径测试按 `realpathSync.native` 的规范路径比较；不修改生产路径策略，不移除目录穿越、秘密文件或符号链接拒绝断言。
- 本轮本地 `npm run check` 通过（Python 243 项，1 项安装专用测试跳过）；`npm run check:m0` 完整通过；定向风格/路径测试 15/15、来源登记测试 11/11 通过。生成器重复运行保持相同字节，27 个源文件/镜像与 HEAD 字节一致。

修复仅涉及跨平台检出、快照及测试，不放宽事实/授权/发布门禁；远端结果以修复提交对应的 Actions 为准。PR 继续保持 Draft，不在本轮合并或发布安装包。
