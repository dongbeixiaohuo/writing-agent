# RC64 反馈修复：自动搜索、HTTP 来源与核查可解释性

日期：2026-10-03。本文记录 RC64 测试后的源代码修改，不代表已有 RC64 安装包包含这些改动。

## 复现与根因

- 对用户提供的 13:46:37 失败步骤进行了只读事件核对：Tavily 此前两次均已返回目标国新办网页，但目标为 `http://`。
- 搜索来源登记原先只匹配 `https://`，导致 `read_fact_source` 找不到刚搜索到的 HTTP 来源，在发出网络读取之前报 `FACT_SOURCE_NOT_IN_LEDGER`。
- 该次失败是单个工具步骤失败，不是整轮模型无响应、Tavily 搜索超时或整轮最终失败；后续核查运行实际上完成。
- 桌面每条检索词弹窗来自宿主的逐次授权回调。旧版统计是新轨迹下仍保留的旧 UI。完成提示则是桥接层固定常量，未使用已保存的逐条核查结果。

## 实施范围

1. 桌面保存的搜索开关作为自动检索公开事实的授权，不再逐次弹窗。设置页和说明文档明确外发范围与隐私边界。其他未显式采用此模式的宿主仍默认拒绝未授权外发。
2. HTTP/HTTPS 来源均登记并可跨运行时恢复读取。事实来源读取按原协议发送，不强制 HTTPS；传输层新增 HTTP 请求支持，重定向仍逐跳校验。继续阻止本机、内网、元数据地址与 URL 内嵌凭据，不开放模型凭空指定的任意来源。
3. 移除“查看旧版分段统计”。新轨迹继续保留真实输入/输出、技术代码与时序；增加模型首包/断流、搜索服务、来源读取、DNS、安全规则、来源记录校验和事实核查提交等失败解释与处理建议。未知外部原因不猜测。
4. 核查通过后，用保存的 assessment 生成正文/标题/配文范围、逐条事实、结论、依据和来源。仅模型复核、没有客观主张及历史明细缺失均有明确说明。最多展开 8 条，其余提示查看核查详情；不新增总结模型请求或搜索。
5. 保留最终交付检查：总结仅在当前稿件满足原有正式交付条件时展示，不用“搜索成功”替代事实核查通过。

## 搜索预算与关闭行为

- 每个核查运行最多 6 次不同检索尝试（含失败）；同一查询使用已有结果，不重复外发。
- 自动模式不会继续复用旧版“授权失败/未授权”的缓存来阻断搜索，历史尝试仍计入预算。
- 单次搜索总时限仍为 20 秒，单个 HTTP 请求最多 8 秒；双服务共享时限并为备用服务保留机会。
- 来源原文读取仍有 20 秒整体上限。取消后不继续付费回退。
- 关闭全部服务后不再发出搜索或来源读取请求，仅用已有材料与模型复核，并披露未联网验证。
