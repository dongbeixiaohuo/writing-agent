# 跨 Agent 输入去重与按需上下文

## 范围

延续 RC67 事实核查输入膨胀的排查，优化意图识别、作者交流、导演调度、提纲、初稿、审校、集中修订、语言终审及配图上下文。保留此前工作区里的素材标识、HTTP 错误说明和交付指引修改。

仅调整发送给模型的视图，不迁移或删除用户项目、稿件、证据台账、核查报告和工具事件；没有调用真实模型或付费搜索，没有打安装包、推送或发布。

## 实现

- `agent-context.ts` 按职责组织作者上下文：意图识别不附整篇正文和逐块副本；讨论用完整正文一份；局部改稿用带稳定 ID 的完整正文块，不再同时附同一篇纯文本。
- 保留本次传入历史中的全部用户原话、当前待确认审校成果、最近助手交流、作者偏好和锁定信息。较早助手长文改为消息序号索引，可按需读取；不是固定长度裁断正文尾部。
- 已解析的确认/标题选择/核查交接只传绑定版本与决策所需字段，不再重复传全部项目状态。语义判断、版本校验和单次确认权限未改。
- 导演只接收核查状态、版本、范围及未解决主张，不同时接收完整结构化报告与同内容 Markdown。未解决包括非 SUPPORTED、部分支持、红色风险及显式阻断项，不能只看 SUPPORTED 状态。
- 新增只读 `read_author_fact_check`：讨论需要具体依据时，读取当前项目已保存的完整结构化核查报告，不重新检索、不制造核查通过状态。
- 下游专家复用证据的无损共享来源表；全部主张、引句和适用范围保留。外部网页文章改为授权目录，必要时按需补读；研究阶段仍正常读取原材料，非网页输入、作者一手材料和要求保留。
- 集中修订里只去除与已附审校工件逐字一致的助手报告，替换为工件引用。作者的引用、反对意见以及内容有变化的报告不去重。
- 工具历史去重只处理成功且版本/内容完全匹配本次已附上下文的读取。错误、旧版本、未附来源和有损报告投影不删减。原工具结果继续保存在事件和运行时历史中，后续不适用投影时仍能读到全文；请求快照及内容哈希记录真实发送的视图。
- 材料读取凭据回看同一运行中已实际发送的持久化请求。后续精简请求不撤销此前完整读取，但材料版本、内容、信任标签或权限变化仍要求重新读取；目录存在不代表读过。
- 运行记录的“输入”页增加构成统计：系统说明、任务、正文、证据、素材、历史工具结果、工具定义及其他状态。统计消息内容与工具定义字符，不是 Token/费用，也不同于格式化 JSON 展示长度。

## 验证结果

- `npm run test:runtime`：338/338。覆盖逐阶段确认、重启与中断恢复、版本/锁定门禁、工具快照及历史原文保留。
- `npm run test:legacy-parity`：80/80；另新增完整核查报告按需读取集成测试 1/1，通过真实临时 SQLite + 脚本模型验证，不是联网模型语义测试。
- `npm run test:bridge`：95/95；`npm run test:ui`：100/100。
- `npm run test:confirmation`：16/16；`npm run test:fact-search`：44/44。
- runtime、web、desktop TypeScript 检查及桥接类型生成通过。
- `npm run build:desktop` 通过；保留已有 MarkdownContent 同时静态/动态导入的非阻断警告。这是构建，不是安装器测试。
- 输入统计有总量分项相等、无原文泄漏和 UI 展示测试；下游材料工具保留按需读取，已附工件不重复提供读取入口。

回归中修正了两类测试假设：分片读取测试必须使用不能直接内联的大材料；已附全文的读取工具历史应验证引用指向同一完整正文及持久化原文，而非要求请求再次携带副本。没有放宽未读材料、版本或核查门禁。

## 尚未验证

真实 MiniMax 的端到端耗时、Token 使用、是否额外补读及最终文章质量仍需代表性样例对照。不能把字符缩减率当作耗时降幅。用户安装后的界面体验与安装包本身不在本次验证中。

## RC68 公开发布前复验

发布前重新执行完整 `check:runtime` 时，作者对话的三项集成回归失败：分类请求仍含正文、已解析的核查交接仍带完整状态、完整核查详情读取工具未注册。复查确认 `agent-context.ts` 的投影函数虽已存在，但 `author-conversation.ts` 仍未接线；上一轮本地安装包的桌面检查没有覆盖这三项。上面的旧能力回归成功记录不能作为该本地包作者对话优化已生效的证明。

已将实际作者入口接到按角色投影，已解析交接仅带决策与绑定版本，并注册只读 `read_author_fact_check` 及相应工具白名单。三项原失败测试按原断言重跑全部通过，runtime TypeScript 检查通过；没有删除或放宽断言、事实门禁与确认权限。公开 RC 必须重新锁定提交、完成 CI 并构建，不能上传此前本地测试包。
