# 对话短横线导航：实现与验证

日期：2026-10-23。范围仅为对话滚动导航；不改变写作流程、模型请求、存储协议或用户数据。导航实现验收后，按用户要求生成 RC89 本地测试安装包；未执行安装/升级、推送或替换 RC88 公开下载。

## 行为

- 用右侧居中的短横线替代满高 minimap、比例长块及视口框。普通滚动条、滚轮和触控板保留。
- 最多显示 16 个等间距定位点；数量更多时抽样保留首尾与当前消息，短窗口按高度减少。当前点加深、加长，点击区域为 32px 宽。
- 点击按消息实际位置跳转；导航聚焦后可用上下方向键逐条切换，Home/End 到首尾。只处理组件内按键，不注册全局快捷键、不拦截 Ctrl/Meta 组合键。
- 导航与原生滚动条错开，正文始终预留稳定的右侧空间，窄屏也不遮挡文字。不能在导航挂载后才增加边距，否则首次自动跟随可能因正文换行而偏离末条消息。
- 内容尺寸及 DOM 文本变化会更新定位；流式回复不增加消息数量时也有效。生成中和减少动态效果模式采用即时跳转，避免平滑动画与自动跟随竞争。
- 切会话清理旧锚点；不可滚动时隐藏，重新溢出时恢复，不依赖导航自身高度来决定是否挂载，避免复发 RC48 的自锁问题。
