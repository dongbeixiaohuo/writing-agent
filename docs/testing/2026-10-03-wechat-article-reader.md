# 公众号文章读取迁移与验收

日期：2026-10-03。修改前检查点：`acd458b`。本记录针对源代码和桌面构建，不代表已安装的 RC65 已更新。

## 根因

- 旧 Claude Code Skill 的文章提取能力没有接入桌面首次需求交流：该路径根本没有 `read_author_web` 工具。
- 已有网页工具要求写作方向先确认，无法在“先读这篇文章、再一起讨论”的阶段使用；返回值也只有材料标识，没有正文。
- 微信文章需要按 `#activity-name`、`#js_name`、`#js_content` 提取。普通 body 文本提取会混入导航或把验证页当成正文。
- 对用户指定链接，默认 Node 阅读器标识收到微信验证页；本机普通浏览器能打开文章。使用宿主实际 Electron 浏览器标识后收到正常文章响应，但其 HTML 超过默认 2 MiB 限制。

## 本次实现

1. 在需求交流首轮、后续方案讨论及已有稿件讨论中提供链接读取。仅使用用户本轮提供的公开 HTTP(S) 地址，不需要开启 Parallel/Tavily，不进行开放式搜索。
2. 桌面将实际 `session.defaultSession.getUserAgent()` 传给固定 DNS 的安全读取器；不复制 Cookie、登录态或 Authorization，不伪装微信客户端、不操作验证码。仅作者链接读取器显式采用 8 MiB HTML 上限；其他读取器的默认 2 MiB 不变。
3. 提取标题和正文段落，移除脚本等活动内容；正常正文提到“安全验证”不误判。验证、删除、受限和缺正文分别报告，失败页面不入库。
4. 保存第三方参考材料（`web_snapshot` / `external_untrusted`），立即向模型返回最多 12,000 字符预览。后续用 `read_material` 分段读；偏移量按 Unicode 字符计数，避免 emoji 导致断段。
5. 需求阶段不创建或确认写作简报；形成待确认方案时保留网页材料，后续无需重新发送链接。材料不是作者亲历，也不代表事实核查通过。已有项目读取仍保留原有材料绑定与幂等恢复规则。
6. 每轮最多 3 次外部网页读取尝试；单次获取总时限 15 秒，可取消；提取文本上限 100,000 字符，超限不作为完整材料导入。后续本地分段读取不访问网站。
7. 运行记录显示域名、标题、保存字符数和实际失败原因。换模型重建服务后保留宿主读取器。

## 验证

### 用户链接的真实网络读取

- 链接：`https://mp.weixin.qq.com/s/n4l7X-i8PDyWqOxPE6V8tA`
- 读取器：项目 `SecureWebFetcher`，真实 Electron 44 默认 UA，8 MiB 上限，固定 DNS 与重定向安全检查保持启用。
- 标题：重磅！糖尿病最新共识，首选二甲双胍要成为历史了？
- 公众号：丁香园。
- 提取 4,455 字符，`truncated=false`，约 2.1 秒，最终仍为原文章路径。未输出/保存完整文章到代码库，未下载媒体。
- 这是网页读取实测，不是对文中医疗主张的事实核查，也不是所有公众号链接的可用性保证。

### 自动化回归

- 对话：首轮读入、失败页不入库、禁止联网时不提供读取工具、后续普通讨论/方案提交两条路径都能继续读取已存材料。
- 材料工具：确认前导入、确认后绑定、HTTP、3 次上限、取消、截断拒绝、重复操作幂等、未绑定材料恢复、Unicode 长文偏移。
- 桌面宿主：切换模型重建服务后仍使用注入的读取器；首轮材料保存成功且未擅自确认方向。
- 网络与解析：真实 UA 注入、无 Cookie/Authorization、非法头拒绝、微信段落提取、验证码重定向、正文关键词不误判、删除/缺正文、私人网络与重定向防护。
- 对话和宿主编排测试使用模拟模型，不冒充真实模型端到端验收，不消耗用户模型 API。

检查命令：`npm run test:runtime`、`npm run test:conversation`、`npm run test:legacy-parity`、`npm run test:fact-search`、`npm run test:bridge`、`npm run check:desktop`。

结果：运行时 315、对话 86、旧能力 71、事实搜索 41、桥接 91、桌面 47，合计 651 项通过。桌面 TypeScript、生产构建、13 文件分发边界和 `git diff --check` 通过。最终构建的 `main.cjs` 已核对包含实际宿主 UA、8 MiB 作者网页读取配置及微信错误识别。Vite 仍有原有 `MarkdownContent` 同时被静态/动态导入的非阻断提示，本次未改动该组件。

## 边界

- 不支持绕过登录/验证码、已删除文章、纯图片正文 OCR 或音视频转写；遇到这些情况说明原因，用户可粘贴已取得的正文。
- 未改用户真实项目、模型 Key 或搜索配置；未推送远端，未打包或替换安装器。
- 旧 `claude-runtime` Skill 保留不变；本次在独立应用实现对应能力，不依赖 Claude Code。
- 子任务：公众号解析与传输兼容由 `gpt-5.6-sol` / `high` 独立处理，因涉及网络安全与真实网页差异；主线程负责入口、持久化、桌面注入与整合回归。未获得可核算的 token/费用数据。
