# rc.52：回复角色标记与下一步收口、关闭确认、设置页体验七项

日期：2026-09-28。范围：对话回复的 agent 标记与"下一步"结尾、桌面端关闭确认、设置页模型管理交互（绿点、内联编辑、下拉预设、打开配置文件）；不修改事实核查口径、写作工作流门禁、存量项目数据或凭据。网络搜索继续推后。

## 需求与修改（用户报告七项）

1. **回复结尾必须说清下一步**（提示词层）：作者对话契约新增硬性要求——回复结尾必须有明确的「下一步」段，写清轮到作者做什么（确认/选择/补充什么，或明确"不需要你操作，我将继续…"），禁止含糊总结收尾；事实核查阶段的收尾说明同样钉死：通过就写"下一步：可以导出发布"，有阻断就写"需要你处理第几项后重新核查"。
2. **每条回复标记是哪个 agent**：`respond_author` 的保存结果现在带上 `role`；bridge 把角色映射为中文标签（写作助手/事实核查/标题策划/编辑审校等 21 个角色全覆盖）写入时间线条目的 `actorLabel`；UI 在无阶段徽标的回复上显示角色徽标头，底部署名从笼统的"Writing Agent"变为具体角色名。
3. **点 X 先确认**：生产模式下关闭主窗口先弹原生对话框「最小化 / 退出程序 / 取消」（默认最小化，可取消）；退出才走 before-quit 清理链路。冒烟与测试模式不装这个拦截，避免阻塞自动化退出。
4. **验证通过的供应商显示绿点**：连接验证通过后在供应商目录里持久化 `verifiedAt`（只写状态字段，不回写 config，保留预设 extraBody 的读取时填充语义）；状态点在"已验证"时变绿，重启后仍绿。重新保存配置会清掉该标记，保存后的自动验证再重新打上。
5. **添加供应商不再跳页**：编辑器改为在已保存供应商列表下方内联展开并自动滚动到可视区，列表全程可见；保存成功/失败的提示都在列表上下文里。
6. **预设选择改下拉菜单**：删除网格卡片式 ProviderPresetPicker（含搜索/筛选/分页），换成按供应商分组的单个下拉（`PREFERRED_PROVIDER_PRESETS`，即 rc.49 起新选择可见的 99 项，选项标注协议）；编辑存量配置时仍是折叠的"当前预设 + 更换"模式。
7. **打开配置文件**：模型设置标题行新增"打开配置文件"按钮，经新 RPC `revealProviderConfig` 调 `shell.showItemInFolder` 定位 provider.json（Key 在 Windows 凭据管理器，文件里本就不含密钥）。
