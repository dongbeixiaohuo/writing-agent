# rc.36：等待可见性、阶段语义与标题核查恢复

日期：2026-09-25。范围为用户“中秋节不吃月饼”现场反馈。原数据库只读在线备份；所有模型请求及写入均在 TEMP 隔离副本，未修改原项目、未自动安装。

## 现场证据与根因

- 截图的 62/78/208 秒是多次模型请求的累计用时，不是服务商连续没有输出的时间。对应请求首个有效内容约 5–6 秒，提纲请求 145 秒内有 1350 个内容事件。有效内容包含工具参数，不能全部等同于可公开正文；程序未展示可读素材，造成长时间空白。详见 `output/rc36-compact.log`。
- 方向确认摘要作为 user message 使用纯文本气泡，且标题直接接在冒号后。现使用安全 Markdown 渲染并兼容旧消息换行，不执行 HTML 或不安全链接。
- 标题已保存，不是用户没选：正文修订使旧事实结论失效，同时旧逻辑也把标题选择判定失效，重复要求选择。现保留标题选择意图，但新正文必须重新核查；从过期候选发起新的选择仍拒绝。
- 作者交流被强制保存标题，却允许委派到没有选题保存工具的核查专家。其文字报告被拒绝后重复尝试，最终达到上限。现确定性操作优先、能力最小化。
- 追加真实回放又发现恢复提示仍要求 `respond_author`，而当前只提供 `request_author_fact_check`。现可用工具、必需操作、toolChoice 与输出纠正共用同一程序契约；确定性操作时不把文字解释冒充成果流出。不提高原调用上限。
- 专项核查仅接收正文/研究账本，漏掉授权原始需求材料；其读取工具也缺少 material 权限。现注入授权材料的有界片段、来源角色及截断定位，并提供仅限授权材料的续读。作者补充作为不可信上下文，不能自动升级为已验证事实或亲历授权。

## 体验及专家定义

1. 处理中显示真实的授权材料节选、研究说明、正在核对的原文。研究账本 JSON、工具调度参数及未经保存的核查结论不出现在普通对话中。临时区跨请求保持，最终回复开始后隐藏，执行结束后移除，不写入永久消息。
2. 研究 content 即使先于 stage 字段返回也能预览，不再因 JSON 字段顺序积攒内容；公开提纲等继续使用现有文本流与 Harness 原文保存。
3. 读者审校明确模拟平台读者“点开→继续/弃读→读完感受→分享动机”，补齐朋友圈熟人场景。模拟不是实际调研，不虚构 CTR，不承诺热文；私人写作不强加传播目标。
4. `language_review` 仍映射原版 `humanizer`，界面明确标注“去 AI 味与语言润色”。保持最小修改、保留作者声音、禁止编造亲历。
5. 运行记录取消抽象任务计数，区分需求交流、写作流程、改稿讨论和专项核查。流程按阶段列出专家职责、保存状态及可展开的分派/返工说明；底层执行段、请求和工具明细仍可查，不把请求数当阶段数。

## 红绿测试与真实回放

- 新增 Markdown 气泡、阶段职责、临时素材跨请求保持、研究内容先返回、账本字段隐藏、核查虚假通过不闪现、标题跨正文修订保留、错误委派拒绝、文字结束后的正确工具纠正、核查原始材料输入等测试，均先复现失败后修复。
- 相关应用/协作/事实存储回归 117 项通过；最终改动后相关集合 77 项通过，随后研究顺序补测 14 项通过。Legacy parity 56、Conversation 65、Bridge 60、UI 66 项通过。计数为不同命令的重叠集合，不相加当独立覆盖量。
- Desktop 类型、34 项测试、生产构建与 13 文件分发边界通过；Runtime/Web 类型检查通过。
- 实际 MiniMax-M3 验证保留成功及失败过程：初次 4 次请求恢复成功；补材料后曾把整篇散文一概无事实放行，人工检查判定不合格；再回放暴露工具纠正冲突，16 次无工具调用失败。没有把这些结果当验收通过，也未交付中间包。
- 最终修复回放：1 次核查交接 + 6 次正式核查请求，首个内容 3.4–4.5 秒，总模型请求耗时约 59 秒。成功保存 8 条判断，保留真实亲历缺口，未重选标题、未改正文、未自动放行。证据 `output/rc36/real-fact-recovery.json`；失败过程见 `output/rc36-real-final.log`、`output/rc36/real-fact-recovery-overgeneralized.json`。
- 最终桌面成品使用本地 SSE 服务隔离验证：素材先显示→最终提纲部分显示且尚未保存→完成后单份成果与确认问句→临时区移除；确认摘要 Markdown、九阶段专家职责也通过。该测试不请求商业服务；真实模型验证与原生界面验证是两条证据链，不宣称原生 UI 全程连真实模型跑完。

## 剩余边界

本轮是专项修复，不提升整个项目最终用户验收状态。服务商真实首包/流停滞仍可能发生，程序不伪造素材或思考；没有收到可公开内容时如实显示等待。事实判断仍含模型语义判断，工程门禁不等于模型永不误判；保留代表性负例，不能把“散文”用作整体豁免。此历史稿仍有模型新增的具体场景，需要用户决定删除、改成非亲历表达或提供真实依据，不能替用户确认。安装升级及原会话人工观感待用户复测。
