## 优先体验四件事

1. 点击左侧 **CR002 missing 桌面体验**。材料只有 `test`，应该看见具体问题和“写作已暂停”，没有正文或全部完成。可在主对话直接回答；只回复“继续”不应跳过缺口。
2. 点击 **CR002 outline 桌面体验**。应自动回到原会话，显示修改后的提纲和确认卡。标题、列表、粗体应已渲染；长内容可在预览中滚动，修改入口和确认标题仍能看到。输入修改意见应先重做提纲，不直接进入正文。
3. 点击 **CR002 complete 桌面体验**。这里保留真实失败、核查阻断和预算停止，**没有已经成功验收的完整写作结果**。用于检查导演安排、阶段成果、阻断和错误呈现；不能把既有工作稿当作可交付成稿。
4. 点击 **新建对话**，等待几秒，再输入要求。不能被后台刷新拉回旧会话；左侧“当前项目”和“正在查看”应与你实际操作一致。设置 → 关于应清楚显示 `1.0.0-rc.7 测试候选版`。
