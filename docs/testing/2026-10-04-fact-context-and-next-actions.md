## 修改内容

- 预览更名为“写作要求与参考素材”。按已保存简报区分“目标读者”“发布平台”，网页素材使用文章显示名称，其余原话显示“需求补充 + 内容短摘”。完全重复的原话和裸链接不重复展示，不用关键词猜测作者意图。
- HTTP 与 HTTPS 公开来源继续可读。读取器保留真实 HTTP 状态，沿工具错误、运行记录、UI 展示传递；区分来源网站拒绝访问、页面不存在、限流、服务器异常。旧日志没有状态码时不猜测。失败页不冒充正文，同一运行同一 URL 的已知 HTTP 拒绝不再重复发网络请求；新运行可重试。SSRF、重定向与正文类型检查保留。
- 事实核查使用完整当前正文、选定标题/配文、全部证据条目与明确作者授权。重复的来源元数据合并为引用表，限定条件、引句、证据编号和未核实状态不删除。外部素材改为授权目录，需要某条事实的上下文时读取；一手材料和需求原话仍提供。
- 全流程事实核查不再重复注入写作简报模板，保留作者的实际补充；已完整提供的正文/证据不要求再次读取。专项重新核查直接提供绑定的正文/证据，成功提交后直接展示持久化结论，不再请求模型另写结束语。版本绑定和事实门禁不变。
- 提示词要求先提取实际写入文章的可核实事实，再对照来源；不逐条审查未进入文章的账本条目，不审文风。相关事实共用来源，确有事实疑点仍核对；每轮搜索上限仍为 6 次（含失败），缓存结果不新增检索费用。
- 核查通过、配图建议和配图确认后，明确给出“查看当前稿件 → 选择格式 → 导出文章”的本地保存路径，说明不会自动发布。
- 无绘图模块时默认 1 张封面、确有必要才加 1–2 张正文图；每张只给位置、用途、可复制 Prompt 和图片说明。取消额外禁画清单、设计交付手册及可选偏好的重复确认。提交方案后直接展示已保存的 Prompt，不再额外调用模型重复写一轮方案。图片未生成的状态不变；配图不阻挡已通过核查的文字稿导出。

## 真实记录与网络取证

## 验收重点

1. 已确认读者/平台的项目写作中，预览菜单能区分要求与文章，不显示三项相同泛称。
2. 读取拒绝访问的站点时，运行记录显示真实状态与处理方向；不把网站拒绝解释成禁用 HTTP 或模型故障。
3. 核查完成后可直接找到导出入口；未能读到原文的限制仍明确，不能宣称外部查证全部成功。
4. 请求配图建议后能直接复制 Prompt；不必回答人物、图库、比例等非必要问题才能交付文字稿。
5. 真实模型可能主动补读材料或检索，不能承诺固定请求数、固定字数或确定的耗时降幅。
