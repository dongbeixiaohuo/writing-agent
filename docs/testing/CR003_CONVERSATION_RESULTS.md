## 已实现

- 空工作区、新项目和旧的未确认项目均可直接表达想法，无需先填名称、读者、字数等字段。手动字段工具放入“高级设置（可选）”。
- 原始用户消息按未核实来源保存；未知仍未知。Agent 的建议方案固定为共创，不可自授自治权限，不得伪造材料或亲历授权。
- 回复、摘要、版本和来源由本地 runtime 持久化；澄清角色没有写正文权限。方案摘要由工程层按实际 brief 生成，不信任模型省略关键字段。
- “好的”等整句短确认或版本绑定按钮，均可同会话进入写作；否定、修改或复杂新答复先使旧方案不可执行，重启仍失效。
- 对话澄清不再显示“全文完成”或虚假的写作阶段进度。正常写作依旧受 CR-002 导演委派、独立审校、共创暂停和事实门禁约束。

## 用户桌面复测

1. 关闭当前 Writing Agent，安装 `output/desktop/Writing-Agent-Setup-1.0.0-rc.8-x64.exe`；设置→关于核对 rc.8。
2. 点击左侧项目区的“+”，直接发“我想聊聊四十岁以后的生活，还没想好写给谁”。不应出现必填向导或立即生成全文。
3. 回复“不确定，你先给我两个切入角度”，再说“选第二个，语气像朋友聊天，别编造我的经历”。观察是否理解上下文，而非依次索要字段。
4. 看到建议后发“先别写，我想换成给刚退休的人”，然后退出重开。旧建议不能继续执行，已有交流必须保留。
5. 新建议符合预期时回“好的”，或点击“按这个方向继续”。应在同一对话进入写作，并展示提纲、等待反馈，不应一次跑到底。
6. 直接在主输入框要求修改提纲；确认修改结果后再推进。问题、缺材料和阻断必须在当前对话可见。
