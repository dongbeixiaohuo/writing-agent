## 实现

- 新建纯数据的 public-stage-output 契约，集中定义七种面向作者的 Markdown 成果及中文标签。协作请求策略、实时预览和 UI 共同使用；不再分别维护遗漏的白名单。
- 三种审校与其他文本成果一样支持普通增量、content-first 工具参数和保存前后稳定消息标识。角色指令要求输出作者可读的审校建议，不输出推理、调度指令或内部字段。结构化研究账本和事实核查数据仍不当作普通文本直接流出。
- 预览仍不等于保存；工具校验、独立上下文、材料授权、作者确认及事实门禁保持不变。
- 以 runtime 执行段为生命周期累计开始时间与请求序号。请求切换、同段自动失败重试不重置累计时间；暂停、停止、完成后清理，下次用户继续重新计时。单请求开始时间仍保留。
- 主界面显示“本轮已用时”；运行记录标签明确“7 个任务 · 本轮 N 次请求”，执行时 N 随实际请求增长。历史解释任务/执行段/请求的区别，不为凑数字制造新任务。
- readiness=false 时不向导演提供 director_decide。保留读取和 assess_writing_readiness；真实缺口通过 needs_input 提问，通过评估后才开放调度。底层拒绝策略仍在。
