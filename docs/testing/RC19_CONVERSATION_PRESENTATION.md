# rc.19 主对话信息分层与稿件阅读

日期：2026-09-21。用户反馈主对话反复出现“读取参考材料”“读取现有稿件”、内部拦截及自动纠错；希望主对话以交流和成果为中心，将详细运行信息及完整导出设置放到专门入口。

## 原因与调整

- Timeline 原先无差别展示持久事件投影的每条工具活动；主对话底部又直接挂载完整导出表单，挤占交流空间。
- 主对话仅展示用户/助手交流、已保存的阶段成果、明确需要用户处理的暂停和终止状态。工具读取、内部重试和导演调度原文不再逐条显示；每轮运行增加可展开的“执行详情”，保留对应运行的诊断信息。底层工具执行和日志未删除。
- 工作中显示当前写作阶段或“正在整理你的想法”，真正的核查阻断与检查点仍在主对话中呈现，不以隐藏错误代替解决问题。
- 主对话只保留轻量“当前稿件 / 查看当前稿件”入口；通过核查和未完成核查分别标注，不把工作稿冒充定稿。
- 稿件与版本默认进入 Markdown 阅读视图，可转到导出与备份、编辑差异、材料与过程、历史版本、核查与来源。窄面板的标签可横向滚动，阅读区另有明确导出入口。
- 完整导出组件通过面板插槽复用，保留桌面另存为、版式选择、回执定位以及正文绑定门禁；不是换成只保存到工作区的另一套导出。
- 阅读预览原先取正文工作标题；现在复用正式交付的已锁定标题解析及首标题移除规则，仅改变阅读投影，不写回正文，不自动选择标题。
