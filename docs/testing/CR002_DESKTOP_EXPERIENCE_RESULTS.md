## 修复内容

- 导演 dispatch/ask/rework/finish 是真实请求和持久决策，专家接收输入版本、任务说明、预期产物及独立工具权限。
- 三类初审读取同一初稿、看不到彼此意见、不能直接改正文；主笔集中修订。语言润色按迁移源 humanizer 的主笔写权限处理，不把审校报告当正文。
- 缺口立即等待；同响应后续工具不执行。共创提纲意见触发返工并重新确认，失效下游产物但保留历史。
- 工具参数 schema 错误仅在完整 JSON、已声明工具条件下允许有限纠正；原响应不执行，仍计同 run 预算。
- 新桌面任务默认最多 64 次模型请求 / 96 次工具调用、2 次重大返工、每请求 2 次重试。真实共创包含恢复重读和再确认，原 48/64 默认缺乏正常交互余量；旧任务预算不变，耗尽记录不改写。该上限仍不保证任意多轮共创都能完成。
- 主对话展示导演决定、渲染后阶段成果与具体问题；事实 blocked 不再显示完成勾号或整篇完成。
- 重开默认显示已选择的会话；长提纲预览保持展开并可滚动，避免把确认标题挤出可视区域。
