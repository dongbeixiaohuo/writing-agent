## 历史实测与持续适用的局限

自然语言确认与标题连续性已有 [rc.54](RC54_CONTEXTUAL_CONFIRMATION.md)、[rc.55](RC55_STAGE_CONFIRMATION_RECOVERY.md)、[rc.56](RC56_TITLE_SELECTION_CONTINUITY.md) 专项证据；不据此宣称任意模型、任意长历史都可靠。当前回归以最终执行记录为准。

[搜索记录](FACT_SEARCH_SETTINGS.md)区分三层：搜索返回摘要、成功读取来源正文、报告保存。Parallel 本次 5 次模型请求、2 次搜索完成；Tavily 已有当日实连证据，部分来源原文读取失败时使用摘录并披露。关闭搜索允许完成模型复核和导出，但必须显示未联网、可能有事实错误；联网也不保证绝对准确。

rc.57 成品从 OneDrive 路径启动曾出现 GPU 崩溃，同字节复制到本机 TEMP 后握手通过；具体环境原因未确定。RC 建议使用默认本地安装目录，不承诺云同步安装目录兼容。新候选必须取得 Windows 标准安装位置的启动证据，不通过关闭 sandbox 或系统防护绕过。

最终安装包的完整人工交互、所有服务商、历史项目组合、旧 Tauri 数据迁移、所有 Windows 环境尚未穷举；公开 RC 用于收集这些反馈。保留重要稿件备份，不把自动脚本成功包装成全部用户体验验收。
