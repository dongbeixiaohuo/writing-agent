# 风格内核与仿写验证

这个文件用于解决“形似神不似”的问题。15 维度能抓表层指纹，但真正决定风格的是作者面对新题目时的判断方式。

## 一、证据账本

建模前先摘证据，再下结论。不要直接写“作者犀利”“作者现实主义”。

```markdown
| 观察现象 | 原文证据 | 样本位置 | 功能判断 | 可复用规则 | 适用边界 |
|----------|----------|----------|----------|------------|----------|
| [现象] | "[原文]" | 样本1/第X段 | [用于开头/转折/压强/收尾] | [下次怎么写] | [适用和不适用场景] |
```

判断标准：
- 2 篇以上样本反复出现，才能写成稳定规则。
- 只出现 1 次，只能写成“可能特征”。
- 没有原文证据的结论必须删除。
- 证据账本落盘到 `.claude/styles/_evidence/[风格名]_evidence.md`，不允许用完即弃。
- 认出作者身份不等于可以引入样本外信息：画像、观点、履历全部只能来自样本原文。

## 一点五、量化指纹

节奏是最容易被印象污染的维度（"感觉他爱用短句"）。所有节奏结论必须先跑：

```bash
python "${CLAUDE_SKILL_DIR}/scripts/style_fingerprint.py" [样本1] [样本2] ...
```

脚本给出句长分布、问句/叹句占比、短段占比、省略号/破折号密度、高频句首词。15 维度和风格内核中的节奏描述与实测冲突时，以实测为准。高频句首词（≥3 次）是口头禅的客观下限——没进这个名单的"口头禅"多半是建模者的脑补。

## 二、风格内核

风格内核回答的是“这个作者为什么这样写”。

必须提炼 8 个问题：

1. **首先看见什么**：面对一个新题目，作者先看利益、结构、人性、代价、荒诞、情绪，还是某种关系。
2. **自动排除什么**：作者不会从什么角度写，不会采用什么案例，不会给什么结论。
3. **论证发动机**：作者如何从现象推进到判断，中间靠设问、反常识、利益拆解、历史类比还是个人经验。
4. **素材选择偏好**：作者偏爱什么人、场景、细节、代价和冲突。
5. **情绪曲线**：开头、中段、结尾的温度如何变化。
6. **读者关系**：作者是陪读者想明白、拆穿读者幻想、教育读者，还是替读者说话。
7. **最小可复现配方**：换任意主题时，仍然能复现的 5-7 条硬规则。
8. **判断库（观点指纹）**：作者跨样本反复表达的实质判断、价值排序（如"利益结构 > 道德评判"）、习惯嘲讽和维护的对象。每条附样本出处。这是最难伪造的一层：句式可以套，但"这个作者面对这件事会得出什么结论"套不出来。

## 二点五、区分性检验（防内核塌缩）

风格提取最隐蔽的失败不是"提取错了"，而是"提取出了正确的废话"：设问推进、具体案例、金句收尾、平视读者——这些是**通用好文章公式**，任何优秀写手都在用。由它们组成的"内核"，套到谁头上都成立，等于没有提取。

对内核每一条过两道闸门：

1. **通用基线检验**：把这条规则交给任何优秀公众号写手，他是不是本来就在这么做？是 → 降级到「通用基线」小节，回证据账本再挖一条有区分度的。
2. **库内撞脸检验**：通读 `.claude/styles/` 已有风格文件的 00 节。与 2 个以上库内风格重合的条目同样降级。检验后必须写出「与库内最相近风格的区分开关」：最容易和谁混淆、同一主题两人第一刀有什么不同、看到什么可以一票鉴别。

合格标准：去掉作者名，熟悉风格库的人读内核能猜出是谁。猜不出 = 塌缩，禁止输出。

## 三、形似陷阱

以下内容只能算形似，不算神似：

- 堆高频词、口头禅、连接词。
- 复刻原文的行业案例，而不是复现作者的判断方式。
- 只学开头句式，不学作者为什么这样开头。
- 把作者人设写得很满，但没有写出可执行规则。
- 只摘录原文，不解释原文在文章结构中的功能。
- 把“样本主题”误判成“作者风格”。
- 把通用好文章公式（设问推进、具体案例、金句收尾、平视读者）当成作者指纹——这是最隐蔽也最常见的一种，用「二点五、区分性检验」拦截。
- 用作者的公开人设补全画像，而不是用样本证据（先验泄漏）。

## 四、仿写验证

完成风格文件前，必须用一个样本中没出现过的新主题做 300-500 字仿写，并做双重验证。

### A. 自评分（带溯源）

| 维度 | 0 分 | 1 分 | 2 分 |
|------|------|------|------|
| 切入角度 | 和作者无关 | 局部像 | 第一反应就像 |
| 素材选择 | 乱举例 | 有相似素材 | 选材逻辑稳定复现 |
| 论证推进 | 只摆结论 | 有转折但松 | 推进方式接近原作者 |
| 句式节奏 | 套模板 | 局部相似 | 呼吸感接近 |
| 情绪和读者关系 | 语气错位 | 有相似态度 | 关系和温度稳定 |

约束：每个 2 分必须能指出"仿写的哪一句 ← 对应证据账本哪一条"。指不出来按 0 分计。自评是通胀的（自己写自己评永远接近满分），所以真正的闸门是下面的盲测。

### B. 独立盲测混淆对（硬闸门）

同一个上下文写完仿写再自己找破绽，仍然带着"我为什么这么写"的记忆，证伪力度有限。盲测必须由**独立的无记忆 agent**执行：

1. 从样本截 1 段作者原文（80-150 字），与仿写中功能相近的一段配对，随机打乱 A/B 顺序。
2. 用 Agent 工具拉起 `general-purpose` 盲测员，只给两段文本——不给风格文件、不给作者名、不透露哪段是仿写。让它回答：哪段是仿的？前 3 个破绽是什么？每个破绽属于判断方式/素材/节奏/用词哪一层？
3. 判定：盲测员猜错 → 通过；猜对且含判断方式破绽 → 失败回炉；猜对但仅浅层破绽 → 修正后通过。
4. 对仿写段跑量化指纹脚本，句长/问句占比与样本实测偏差 >30% 判节奏不合格。
5. 盲测员原始回答摘录进风格文件，作为验证留痕。

### C. 反向压力测试（多样本时推荐）

选一个作者立场明确的话题，先按风格文件推演"他会得出什么判断"，再回判断库核对。推演与判断库相反 → 内核只抓了皮。

总分低于 8 分或盲测失败，必须反向修正：

- 如果切入角度低，重写“首先看见什么”。
- 如果素材选择低，重写“素材选择偏好”。
- 如果论证推进低，重写“论证发动机”。
- 如果句式节奏低，补充句式触发条件，不只是列句式。
- 如果情绪关系低，重写“读者关系”和“情绪曲线”。
- 如果推演判断错位，重建“判断库”。

## 五、输出要求

风格文件必须让下游写作 agent 能回答四个问题：

1. 换一个新主题，这个作者会先从哪里下刀？
2. 这一段为什么要这么转，而不是换个普通写法？
3. 哪些写法看起来像，但其实会破坏风格？
4. 面对一个有争议的话题，这个作者大概率站在哪边、嘲讽谁、维护谁？
